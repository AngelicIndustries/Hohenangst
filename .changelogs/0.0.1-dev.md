Initial standalone 512-block height implementation for Minecraft 1.7.10.

- Build at Y=0..511 with upper chunk storage, persistence and network delivery.
- Extend block interactions, tile/entity sections, lighting and heightmaps.
- Support Angelica rendering and shaders, including renderer reloads above the ceiling.
- Adapt Archaic Fix/Phosphor, Hodgepodge and optional EndlessIDs.
- Require matching client/server versions and record the tall-save format through ChunkAPI.
- Keep existing terrain generation unchanged; Biomic integration is deferred.
- Leave companion-specific height handling to Biomic; remove provisional patches of its relighting helpers.
